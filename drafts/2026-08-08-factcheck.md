### 記事1: 特定在留カード、企業の在留確認実務が変わります

**【X投稿】誇張表現の修正**（根拠: WebSearch「特定在留カード 表面 記載項目」複数二次情報）

在留資格・在留期限（満了日）・就労制限の有無はカード表面に引き続き記載されるため、「不法就労確認が困難」は過度な表現。

```diff
- カード表面の在留期間等がICチップ内のみに移行し、目視確認だけでは不法就労確認が困難になります。企業は読取アプリ整備と個人情報保護対応が急務です。
+ 在留期間・許可の種類・許可年月日等がICチップのみに移行し、これらの目視確認ができなくなります。企業は読取アプリの整備と個人情報保護対応が求められます。
```

**【事実】ICチップ移行項目の誤記を修正**（根拠: WebSearch「特定在留カード 表面 記載項目 在留資格 在留期限 ICチップ移行」）

確認結果: カード表面に引き続き記載 → 在留資格・在留期限（在留期間の満了日）・就労制限の有無。ICチップのみに移行 → 在留期間（1年・3年等）・許可の種類・許可年月日・交付年月日。

```diff
- これまでの在留カードでは、「在留資格」「在留期限」「許可の種類」「就労制限の有無」などの情報がカード表面に印刷されており、目視で確認することができました。しかし特定在留カードでは、これらの情報の一部がカード内のICチップにのみ格納され、カード表面には記載されない仕様に変わります。
+ これまでの在留カードでは、「在留資格」「在留期限（在留期間の満了日）」「在留期間（1年・3年等）」「許可の種類」「就労制限の有無」などの情報がカード表面に印刷されており、目視で確認することができました。しかし特定在留カードでは、「在留期間（1年・3年等）」「許可の種類」「許可年月日」「交付年月日」がカード内のICチップにのみ格納され、カード表面には記載されない仕様に変わります。なお「在留資格」「在留期限（在留期間の満了日）」「就労制限の有無」はカード表面に引き続き記載されます。
```

**【事実】ICチップ確認が必要な場面を明確化**

```diff
- この変更により、特定在留カード保有者に対しては、出入国在留管理庁が提供する「在留カード等読取アプリケーション」または専用の読取機器によるICチップ読み取りでの確認が必要になります。
+ この変更により、特定在留カード保有者の在留期間・許可の種類・許可年月日を確認する場合は、出入国在留管理庁が提供する「在留カード等読取アプリケーション」または専用の読取機器によるICチップ読み取りが必要となります。
```
